# ⚰️ Retired Projects

> *"여기 잠들다."*

한때는 다 잘될 줄 알았던 프로젝트들의 무덤입니다. 코드는 죽지 않습니다, 그저 org만 옮겨질 뿐.

## 묘지 안내도

```mermaid
flowchart LR
    a["아이디어 번뜩임 💡"] --> b["개인 레포로 시작"]
    b --> c{"3개월 뒤에도\n건드리는 중?"}
    c -- "응, 진심임" --> d["활성 조직으로 승격"]
    c -- "...아니" --> e["🪦 여기 안장"]
    e --> f["가끔 코드 보러 옴 (조의 표함)"]
```

### 장례 절차

```mermaid
sequenceDiagram
    participant O as 나
    participant P as 한때 사랑했던 프로젝트
    participant R as Retired-Projects
    O->>P: "이거 언제 다시 하지..."
    Note over O,P: (6개월 경과)
    O->>P: 사망 선고
    O->>R: 정중히 이장
    R->>O: 편히 잠드소서 🙏
```

## 여기 잠든 이유들 (대표 사례)

- **AIHQ / Quorum 계열** — 리브랜딩되어 새 이름(Solomon)으로 환생, 껍데기만 남음
- **각종 -legacy, -backup** — "혹시 몰라서" 남긴 스냅샷들
- **한 번 켜보고 안 켠 사이드 프로젝트들** — 가장 큰 무덤 지분
